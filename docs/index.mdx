# Cloud Native Mail Service (CNMS)

CNMS is a Kubernetes operator that runs and manages email servers on
Kubernetes: **Postfix** (SMTP in/out, relay), **Rspamd** with **Valkey**
(spam filtering, DKIM signing, SPF/DMARC checks, rate limits), and
**Dovecot** (IMAP, LMTP, SASL authentication).

The operator is a control plane: it renders configuration for proven
software and manages its lifecycle. Control plane and data plane are
separate — if the operator is down, mail keeps flowing.

**Status:** pre-v1 — API version `cnms.rpp.gmbh/v1alpha1`, subject to
change. Upgrade notes are published for every release.
